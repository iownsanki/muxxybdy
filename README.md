# Happy Birthday Muxxy Ji! 🎂✨
### Customized Birthday Experience — From Sanki to Muxxy Ji

This is a modern, mobile-responsive interactive birthday greeting clone inspired by [storymintstudio.github.io/BIRTHDAY-PART1](https://storymintstudio.github.io/BIRTHDAY-PART1/), fully customized for **Muxxy Ji** with love from **Sanki**.

---

## 🌟 Features Included

1. **5 Interactive Story Slides**:
   - **Slide 1**: Special birthday intro dedicated to Muxxy Ji from Sanki.
   - **Slide 2**: Cosmic bloom animation ("Muxxy Ji, you are literally the universe's favourite creation ✨").
   - **Slide 3**: Sweet reasons why Muxxy Ji is amazing with interactive floating cards.
   - **Slide 4**: Interactive 3-tier birthday cake with real flickering candles! Tapping anywhere blows the candles out one-by-one with smoke puff animations and sound effects.
   - **Slide 5**: The grand finale with heartfelt birthday wishes, popping hearts, dedicated badge (*made with ♥ for Muxxy Ji from Sanki*), replay button, and festive emoji confetti shower!

2. **Ambient Effects & Polish**:
   - **Interactive Background Particles**: Floating cute emojis (`✨`, `🌸`, `💗`, `⭐`, `🎀`, `💫`, `🧁`, `💖`).
   - **4 Swaying Pastel Balloons**: Smooth floating physics with realistic strings.
   - **Aurora Glow**: Drifting gradient background lights.
   - **Sparkle Tap Burst**: Dynamic sparkle trails following clicks and finger taps.
   - **Theme Switcher (🌙 / ☀️)**: Seamless switch between dreamy pastel light mode and magical midnight dark mode.
   - **Built-in Music Box (🎵 / 🔇)**: Sweet Web Audio API synthesizer that plays "Happy Birthday to You", candle blow whoosh sounds, and celebration chimes without needing external MP3 files!

## 🚀 How to Use / View

### 1. Direct Browser Opening (Local)
Simply double-click:
- `muxxy_birthday/index.html` (or `muxxy_birthday/standalone.html`)
in Google Chrome, Microsoft Edge, Safari, or Firefox!

### 2. Hosting on GitHub Pages (Free URL to share on Instagram/WhatsApp/Telegram)
1. Create a new GitHub repository (e.g., `muxxy-birthday`).
2. Upload the files inside `muxxy_birthday/` (`index.html` and `bday.css`).
3. Go to **Settings** → **Pages** → Select `main` branch and click **Save**.
4. You will get a live link like:
   `https://<your-username>.github.io/muxxy-birthday/`
